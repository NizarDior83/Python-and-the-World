## Tips for best results in Gemini

- Use **Gemini 2.0 Flash** or **Imagen 4** for these — the clay 3D style renders best on the latest models.
- Generate at least **4 variations per prompt** and pick the best one — especially for the character, consistency between generations matters.
- For Generations 4, 5, 6 (individual Bito expressions): always use your favourite result from Generation 2 or 3 as a **reference image** — paste it alongside the prompt in Gemini so Bito stays consistent across all four expressions.
- For the Expression Sheet (Generation 3): if Gemini struggles with the 2×2 layout, use Generations 4, 5, 6, and 2 instead — one prompt per expression, then assemble in Figma or Canva.
- **Background removal**: Generations 4, 5, 6 are shot on pure white for easy removal. Use remove.bg, Photoshop's Remove Background, or Figma's background remover. Save as PNG with transparency.
- **Props Pack (Generation 8)**: After generating, cut the image into 4 equal quadrants in any image editor and save each as a separate PNG with transparent background.
- The logo (Generation 1) should look close to a polished app icon. If it comes out too illustrative or too photorealistic, add "clay toy render, soft material, not glossy" to the style block.
- **Asset naming**: Save files exactly as listed under each generation (bito-happy.png, bito-excited.png, bito-curious.png, splash.png, props-pack.png) — the app code references these exact filenames.
